# ADR-0002：插件 = 无沙箱独立子进程 + ctx/IPC 契约

- **状态**：Accepted
- **日期**：2026-10-11

## 背景

需要为插件定义执行模型。可选项从"同进程 `require`"到"完全隔离子进程"。约束:

- 插件来源**可信**(使用者 + 少数朋友),因此安全隔离不是首要目标。
- 但需要**崩溃隔离**与**依赖隔离**(不同插件可各自携带、且版本互不冲突的 `node_modules`)。
- 方法清单里包含"格式转换""压缩"——**这两者本质就是 IO 本身**,因此插件必须**自己拥有读图/写图能力**。

## 决策

**每次插件调用 = 一个 `fork` 出的无沙箱独立子进程。**

- **宿主 → 插件**(`ctx`):
  ```jsonc
  {
    "inputs": { "<key>": "<workdir>/in/<file>" },  // 输入已拷入 workdir
    "params": { /* 已补默认值、已按 min/max 校验 */ },
    "workdir": "<绝对路径>",                          // 插件唯一可写沙箱
    "out":     "<workdir>/out"                        // 建议输出目录
  }
  ```
- **插件 → 宿主**(经 `process.send`,而非 stdout,以便插件自由 `console.log`):
  `{type:"log"|"progress"|"result"|"error"}`;`result.outputs` 为 workdir 内相对路径。
- **入口**:宿主 loader `import()` 插件入口并调用其导出的 `run(ctx)`。
- **输入拷贝**:输入文件**先拷进 `workdir/in`**,以确立"workdir 之外不可触碰"的沙箱不变量。
- **输出名/格式由插件决定**。
- **取消**:杀**进程树**(Windows:`taskkill /PID <pid> /T /F`)。
- **安全**:无沙箱,插件拥有完整 Node 权限;**安装时给一行信任提示**;默认**不限时** + 手动取消,设置可配"最大运行时长"(默认关);v1 **不做**内存/CPU 硬限制。
- **失败处理**:非零退出 → 该项失败(附 stderr 尾部);未发 `result` 即退出 → 报错。批量中的单项失败**不中止**整批。

## 后果

- **收益**:崩溃/依赖隔离;每个插件自带依赖、互不污染;`file` 家族(格式转换、压缩)的 IO 需求天然满足。
- **代价**:每次运行有进程启动与输入拷贝开销;插件以完整本机权限运行,存在信任风险(已接受,并以安装提示缓解)。
- 与 ADR-0003 一并,构成**唯一的**插件执行模型。
